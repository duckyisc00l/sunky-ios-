# Sunky for iPhone

Personal iPhone port of LooneyDude's Sunky games (Parts 1-3, Sunky.MPEG, Silly.TIFF, Sunky the Game 2).
The games run unchanged on OpenGMK (GPL-2.0), an open-source GameMaker 8 runner, ported to iOS.

Keep this repo **private**. Sunky and the games belong to LooneyDude. The game files are downloaded
from Game Jolt at build time and are never stored in this repo.
